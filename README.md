# Museum 2 landing page

Implement landing page according to [Figma design](https://www.figma.com/file/HL3XGt5ZatvJoYBhOaWY5x/museum-prototype?node-id=323%3A1957) - Use BEM and SCSS

Check font styles. Use [Playfair Display](https://fonts.google.com/specimen/Playfair+Display?query=Playfair+Display), [Raleway](https://fonts.google.com/specimen/Raleway?query=Raleway)

- The design 1440px
- Desktop 1280px
- Tablet 640px
- Mobile (> 320px)

1. Run `npm install` (or just `npm i`).

2. Run `npm start`.

3. Open one more terminal window for the next steps.

4. `git checkout -b develop` - to create new branch and switch on it.

5. Write you code in `src` folder.

6. Run `npm run lint` and fix code style errors.

7. Run `npm run deploy` to deploy your solution to `gh-pages`.

8. `git add . && git commit -m 'write a short description of the changes you made'` to save your changes.

9. `git push origin develop` - to send you code for PR.

10. Create a Pull Request (PR) from your branch `develop` to branch `master` of original repo.

11. Replace `<your_account>` with your Github username in the
  [DEMO LINK](https://protocolo23.github.io/Museum_2/).

12. Copy `DEMO LINK` to the PR description.

> To update you PR repeat steps 7-11.
